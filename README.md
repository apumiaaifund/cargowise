## За 30 секунд

**Что это:** CargoWise connector — интеграция с логистической платформой для извлечения и проверки данных о перевозках.

**Кому:** Логистические компании на CargoWise.

**Почему сейчас:** Данные о перевозках разбросаны по системам. CargoWise connector собирает и проверяет их в одном месте.

**Что доказано:** 7 passed. apumia prove → PROVEN.

**Чего не доказано (честно):** Узкая ниша — без контакта в логистике не продаётся.
